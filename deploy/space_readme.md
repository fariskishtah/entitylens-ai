# EntityLens AI

Intelligent Named Entity Recognition & Text Analysis.

Enter English text and EntityLens highlights **Person**, **Organization**,
**Location** and **Miscellaneous** entities with exact character offsets, an
extracted-entities table, live statistics, an entity inspector, and batch CSV
processing. Built on the CoNLL-2003 benchmark; the production model is selected
by validation entity-F1 from four trained architectures (LSTM, BiLSTM,
BiLSTM+CRF, fine-tuned BERT).

Source: https://github.com/fariskishtah/entitylens-ai
